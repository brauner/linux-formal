lfnodev_no_iter_pin -- NoErr (FIX_ITER_PIN off): "iterator advances from an unlinked node"

The iterator putting the current superblock before it advances from it: its reference was
the last, put_super() unlinks the node (L424-427), and the advance (L968 / L1014) reads a
node that is no longer on the list.  The tree keeps the current one pinned (p = sb, L986)
until the next one is pinned.
